# University Course Management System

The **University Course Management System** is a software engineering project focused on designing and documenting a system for managing university courses and related academic information.

The system provides a structured way to manage information related to **students, courses, instructors, enrollment, and academic activities**.

## Project Contents

The project includes documentation and system design materials covering:

* System requirements
* Requirements analysis
* Software Requirements Specification (SRS)
* Use case diagrams
* UML diagrams
